## API Categories

The API covers all major Confluence functionality:

- Content Management (pages, blogs, attachments)
- Space Operations (create, manage, permissions)
- User & Group Administration
- Search and Labels
- Webhooks and Notifications
- Backup and Restore
- System Information and Metrics
